# Artwork

The checkerboard, hedge tile, hearts, trophy, scissors and neutral points star are original assets, with editable SVG sources and PNG runtime exports. The checkerboard/compact arcade interface takes inspiration from the supplied Google Snake reference; no Google artwork or code was copied.

SnakeLogo.png from the supplied project remains the native window icon. The menu uses the actual supplied snake head/body/tail images, combined at runtime by SnakeRenderer, exactly as gameplay does. No extra title mascot is used. Older leaf/rock resource files are retained as unused historical artwork.

All runtime artwork loads from the classpath and needs no network connection.
